# 6_b_Intelig-nciaArtificial
Repositório criado para armazenar atividades, códigos que serão desenvolvidos durante a matéria de Inteligência Artificial da turma B do sexto período.

Conteúdos dos exercícios
Exercícios 1 a 15
Hello, World! — primeiro programa em Python.
Soma de dois números — entrada de dados e operações matemáticas.
Conversão de temperatura — conversão entre unidades de temperatura.
Tabuada — geração de tabuada.
Números Pares — identificação e trabalho com números pares.
Número ímpar ou par — verificação se um número é par ou ímpar.
Verificação de Palíndromo — verificação de palavras ou frases que podem ser lidas nos dois sentidos.
Fatorial de um Número — cálculo de fatorial.
Sequência de Fibonacci — geração da sequência de Fibonacci.
Lista de Números — manipulação de listas numéricas.
Contagem de caracteres — contagem de caracteres em strings.
Ordenação de Lista — ordenação de elementos de uma lista.
Soma dos elementos de uma lista — utilização de sum() e listas.
Média de uma lista — cálculo de média utilizando soma e quantidade de elementos.
O notebook mantém a numeração original dos exercícios; por isso, o exercício 3 não aparece na lista.

Exercícios 16 a 25
Manipulação de Strings — inversão de palavras e frases.
Dicionário de contagem de palavras — contagem da frequência de palavras utilizando dicionários.
Número Primo — verificação se um número é primo.
Jogo de Advinhação — jogo em que o usuário tenta adivinhar um número gerado aleatoriamente.
Matriz transposta — transformação de linhas em colunas utilizando zip().
Busca Binária — busca de um elemento em uma lista ordenada.
Criptografia de Cifra de César — criptografia de mensagens por deslocamento no alfabeto.
Descriptografar Cifra de César — processo inverso da cifra de César.
Validação de CPF — validação dos dígitos verificadores de um CPF.
Classificação de Números — separação de números em positivos, negativos e zeros.

Exercícios 26 a 35
Calculadora simples — operações de adição, subtração, multiplicação e divisão.
Anagramas — comparação de palavras para verificar se possuem as mesmas letras.
Gráfico de Barras — criação de gráfico de barras com dados fornecidos pelo usuário utilizando matplotlib.
Números FizzBuzz — aplicação do problema clássico FizzBuzz de 1 a 100.
Jogo da forca — jogo simples para adivinhar uma palavra.
Ordenação por bolha — implementação do algoritmo Bubble Sort.
Jogo da velha — jogo da velha para dois jogadores, com verificação de vitória e empate.
Anagramas — nova implementação de verificação de anagramas com palavras fornecidas pelo usuário.
Contador de vogais — contagem de vogais em uma string.
Números Fibonacci até N — geração da sequência de Fibonacci até um limite informado pelo usuário.

Exercícios 36 a 50
Gerador de senhas — geração de senhas aleatórias com letras e números.
Funções Recursivas — cálculo de fatorial utilizando uma função recursiva.
Contar palavras em texto — utilização de split() e len() para contar palavras.
Jogo de dados — simulação do lançamento de dois dados.
Lista de compras — programa para adicionar, remover e listar itens.
Remover Duplicatas — remoção de valores duplicados utilizando set().
Números primos até N — geração dos números primos até um limite informado pelo usuário.
Conversor de Unidades — conversão entre metros e centímetros.
Fibonacci em nível — geração de uma quantidade definida de termos da sequência de Fibonacci.
Par ou Ímpar em uma lista — classificação dos números de uma lista como pares ou ímpares.
Calcular a Média e Desvio Padrão — cálculo da média e do desvio padrão de uma lista de números.
Contar números em lista — contagem da frequência de cada número em uma lista.
Ordenação por inserção — implementação do algoritmo Insertion Sort.
Soma dos dígitos — soma dos dígitos de um número inteiro.
Cálculo de frequência de letras — contagem de quantas vezes cada letra aparece em uma string.

Como executar
O arquivo .ipynb pode ser aberto no Google Colab, Jupyter Notebook ou em outro ambiente compatível com notebooks Python.
Os exercícios que utilizam bibliotecas externas ou módulos específicos fazem seus respectivos imports no próprio código.

Objetivo do repositório
O repositório reúne os exercícios desenvolvidos durante a disciplina para registrar o aprendizado dos principais conceitos de Python e servir como material de consulta e acompanhamento da evolução dos códigos.
