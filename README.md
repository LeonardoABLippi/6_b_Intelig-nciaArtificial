# 6_b_InteligenciaArtificial

Repositório criado para armazenar atividades, exercícios e códigos desenvolvidos durante a disciplina de **Inteligência Artificial**, da turma B do sexto período.

## Conteúdos dos exercícios

### Exercícios 1 a 15 — Python Básico

* **Hello, World!** — Imprima "Hello, World!" no console.
* **Soma de dois números** — Solicite ao usuário dois números e exiba a soma.
* **Cálculo da área do círculo** — Solicite o raio de um círculo e calcule sua área utilizando a fórmula `π * r²`.
* **Conversão de temperatura** — Converta uma temperatura de Celsius para Fahrenheit utilizando `F = C * 9/5 + 32`.
* **Tabuada** — Crie um programa que imprima a tabuada de um número fornecido pelo usuário.
* **Números pares** — Exiba todos os números pares de 1 a 20.
* **Número ímpar ou par** — Solicite um número e informe se ele é par ou ímpar.
* **Verificação de palíndromo** — Verifique se uma palavra é um palíndromo.
* **Fatorial de um número** — Calcule o fatorial de um número fornecido pelo usuário.
* **Sequência de Fibonacci** — Imprima os primeiros 10 números da sequência de Fibonacci.
* **Lista de números** — Crie uma lista e exiba seu maior e menor número.
* **Contagem de caracteres** — Conte o número de ocorrências de cada caractere em uma string.
* **Ordenação de lista** — Ordene uma lista de números em ordem crescente.
* **Soma dos elementos de uma lista** — Calcule a soma de todos os elementos de uma lista.
* **Média de uma lista** — Calcule a média dos números de uma lista.

### Exercícios 16 a 25 — Estruturas e Algoritmos

* **Manipulação de Strings** — Inverta uma string fornecida pelo usuário.
* **Dicionário de contagem de palavras** — Conte a frequência de cada palavra em uma string.
* **Número primo** — Verifique se um número fornecido é primo.
* **Jogo de Adivinhação** — Implemente um jogo de adivinhação com números aleatórios.
* **Matriz transposta** — Crie a matriz transposta de uma matriz representada por listas.
* **Busca Binária** — Implemente o algoritmo de busca binária.
* **Criptografia de Cifra de César** — Crie uma função para criptografar mensagens utilizando a cifra de César.
* **Descriptografia de Cifra de César** — Crie uma função para descriptografar mensagens.
* **Validação de CPF** — Implemente uma função para validar um CPF brasileiro.
* **Classificação de números** — Classifique números em positivos, negativos e zeros.

### Exercícios 26 a 35 — Algoritmos e Projetos em Python

* **Calculadora simples** — Realize operações de adição, subtração, multiplicação e divisão.
* **Anagramas** — Verifique se duas palavras são anagramas.
* **Gráfico de barras** — Crie um gráfico de barras utilizando Matplotlib.
* **FizzBuzz** — Implemente o clássico problema FizzBuzz de 1 a 100.
* **Jogo da Forca** — Desenvolva um jogo simples da forca.
* **Ordenação por bolha** — Implemente o algoritmo Bubble Sort.
* **Jogo da Velha** — Crie um jogo da velha para dois jogadores.
* **Verificação de anagramas** — Verifique novamente se duas palavras são anagramas.
* **Contador de vogais** — Conte o número de vogais em uma string.
* **Fibonacci até N** — Gere a sequência de Fibonacci até um número `N`.

### Exercícios 36 a 50 — Python Intermediário

* **Gerador de senhas** — Crie um gerador de senhas aleatórias com letras e números.
* **Funções recursivas** — Implemente uma função recursiva para calcular o fatorial.
* **Contagem de palavras** — Conte o número de palavras em um texto.
* **Jogo de dados** — Simule o lançamento de dois dados.
* **Lista de compras** — Crie um programa para adicionar, remover e listar itens.
* **Remover duplicatas** — Remova valores duplicados de uma lista.
* **Números primos até N** — Gere todos os números primos até determinado valor.
* **Conversor de unidades** — Converta unidades de comprimento.
* **Fibonacci por quantidade de termos** — Gere Fibonacci por número de termos.
* **Par ou ímpar em uma lista** — Classifique os valores de uma lista.
* **Média e desvio padrão** — Calcule média e desvio padrão.
* **Contagem de números em lista** — Conte a frequência de cada número.
* **Ordenação por inserção** — Implemente o Insertion Sort.
* **Soma dos dígitos** — Calcule a soma dos dígitos de um número.
* **Frequência de letras** — Calcule a frequência das letras de uma string.

## Como executar

Os arquivos `.py` e `.ipynb` podem ser executados em ambientes compatíveis com Python, como:

* **Google Colab**
* **Jupyter Notebook**
* **Visual Studio Code**
* **PyCharm**
* Outros ambientes compatíveis com Python.

Os exercícios que utilizam bibliotecas externas possuem seus respectivos `imports` no próprio código.

Para executar os exercícios com bibliotecas como NumPy, SciPy, Pandas e Matplotlib, pode ser necessário instalar as dependências:
