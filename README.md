# 6_b_InteligênciaArtificial

Repositório criado para armazenar atividades e códigos que serão desenvolvidos durante a disciplina de Inteligência Artificial da turma B do sexto período.

## Conteúdos dos exercícios

### Exercícios 1 a 15
- **Hello, World!** — Imprima "Hello, World!" no console.
- **Soma de dois números** — Crie um programa que peça ao usuário dois números e exiba a soma 
deles.
- **Cálculo da área do circuito** — Solicite o raio de um círculo e calcule sua área. Use a fórmula área = 
π * r². 
- **Conversão de temperatura** — Converta uma temperatura fornecida em Celsius para Fahrenheit 
usando a fórmula F = C * 9/5 + 32.
- **Tabuada** — Crie um programa que imprima a tabuada de um número fornecido 
pelo usuário. 
- **Números pares** — Faça um programa que exiba todos os números pares de 1 a 20.
- **Número ímpar ou par** — Solicite um número ao usuário e informe se ele é par ou ímpar
- **Verificação de palíndromo** — Crie um programa que verifique se uma palavra é um palíndromo 
(ex: "radar").
- **Fatorial de um número** — Calcule o fatorial de um número fornecido pelo usuário. 
- **Sequência de Fibonacci** — Imprima os primeiros 10 números da sequência de Fibonacci. 
- **Lista de números** — Crie uma lista de números e exiba o maior e o menor número.
- **Contagem de caracteres** — Conte o número de ocorrências de cada caractere em uma string 
fornecida.
- **Ordenação de lista** — Dada uma lista de números, ordene-a em ordem crescente. 
- **Soma dos elementos de uma lista** — Calcule a soma de todos os elementos em uma lista.
- **Média de uma lista** — Calcule a média dos números em uma lista.


### Exercícios 16 a 25
- **Manipulação de Strings** — Crie um programa que inverta uma string fornecida pelo usuário. 
- **Dicionário de contagem de palavras** — Conte a frequência de cada palavra em uma string fornecida pelo 
usuário. 
- **Número primo** —  Crie um programa que verifique se um número fornecido é primo.
- **Jogo de Adivinhação** — Implemente um jogo onde o usuário deve adivinhar um número 
gerado aleatoriamente pelo computador. 
- **Matriz transposta** —  Dada uma matriz (lista de listas), crie sua matriz transposta. 
- **Busca Binária** — Implemente a busca binária para encontrar um elemento em uma 
lista ordenada. 
- **Criptografia de Cifra de César** —  Crie uma função para criptografar uma mensagem usando a cifra de 
César. 
- **Descriptografar Cifra de César** —  Crie uma função para descriptografar uma mensagem cifrada com a 
cifra de César.
- **Validação de CPF** — Implemente uma função para validar um CPF brasileiro.
- **Classificação de números** —  Classifique uma lista de números em três categorias: positivos, 
negativos e zeros.

### Exercícios 26 a 35
- **Calculadora simples** —  Crie uma calculadora que possa realizar adição, subtração, 
multiplicação e divisão.
- **Anagramas** —  Verifique se duas palavras são anagramas (ou seja, se são formadas 
pelas mesmas letras). 
- **Gráfico de barras** — Use a biblioteca matplotlib para criar um gráfico de barras com 
dados fornecidos pelo usuário.
- **Números FizzBuzz** —  Implemente o clássico problema FizzBuzz para números de 1 a 100.
- **Jogo da forca** —  Desenvolva um jogo simples da forca onde o usuário deve adivinhar 
uma palavra. 
- **Ordenação por bolha** —  Implemente o algoritmo de ordenação por bolha (Bubble Sort). 
- **Jogo da velha** —  Crie um jogo da velha para dois jogadores.
- **Verificação Anagramas** —  Verifique se duas palavras fornecidas são anagramas uma da outra. 
- **Contador de vogais** — Conte o número de vogais em uma string fornecida. 
- **Números Fibonacci até N** —  Gere a sequência de Fibonacci até um número n fornecido pelo 
usuário.

### Exercícios 36 a 50

- **Gerador de senhas** — Crie um gerador de senhas aleatórias com letras e números. 
- **Funções Recursivas** —  Implemente uma função recursiva para calcular o fatorial de um 
número. 
- **Contar palavras em texto** — Conte o número de palavras em um texto fornecido pelo usuário. 
- **Jogo de dados** —  Simule o lançamento de dois dados e mostre o resultado. 
- **Lista de compras** — Crie um programa para gerenciar uma lista de compras, permitindo 
adicionar, remover e listar itens.
- **Remover Duplicatas** — Remova duplicatas de uma lista de números. 
- **Números primos até N** —  Gere todos os números primos até um número n fornecido.
- **Conversor de unidades** —  Converta unidades de comprimento (por exemplo, metros para 
centímetros). 
- **Fibonacci em nível** — Gere a sequência de Fibonacci até um determinado número de 
termos. 
- **Par ou ímpar em uma lista** —  Classifique os números de uma lista como pares ou ímpares. 
- **Calcular a média e desvio padrão** —  Calcule a média e o desvio padrão de uma lista de números. 
- **Contar números em lista** — Conte quantas vezes cada número aparece em uma lista
- **Ordenação por inserção** — Implemente o algoritmo de ordenação por inserção (Insertion Sort)
- **Soma dos dígitos** —  Calcule a soma dos dígitos de um número inteiro fornecido. 
- **Cálculo de frequência de letras** — Calcule a frequência de cada letra em uma string fornecida pelo 
usuário.

## Como executar
O arquivo `.ipynb` pode ser aberto no **Google Colab**, **Jupyter Notebook** ou em outro ambiente compatível com a linguagem Python.
Os exercícios que utilizam bibliotecas externas ou módulos específicos fazem seus respectivos `imports` no próprio código.

## Objetivo do repositório
O repositório reúne os exercícios desenvolvidos durante a disciplina para registrar o aprendizado dos principais conceitos de Python e servir como material de consulta e acompanhamento da evolução dos códigos.
